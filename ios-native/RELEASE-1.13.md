# Move Log 1.13 — Sürüm Hazırlığı (TestFlight)

## App Review Notu (İngilizce — inceleme ekibine)
```
WHAT'S NEW IN 1.13 (since 1.12):

1) PAIR LIVE RADIO (voice chat between two friends)
   - A new radio-call button on friend rows lets a user invite ONE friend to a
     private live voice chat (max 2 participants, technically enforced server-side:
     the room token is only ever minted for the two friends).
   - Invitation flow: invite -> push notification -> accept/decline. Either side
     can leave at any time. Uses the same LiveKit audio infrastructure already
     reviewed in 1.9 (club intercom), scoped down to two people.
   - Microphone permission is requested only when the user joins a call
     (existing NSMicrophoneUsageDescription applies).

2) WALKIE-TALKIE COLLISION LOCK
   - While one party is holding the push-to-talk button, the other party's
     talk button is temporarily disabled with a "talking" indicator, preventing
     both sides from transmitting at once. Pure UX improvement.

3) TACTICAL VIDEO (new optional style for the existing route-video feature, Ultra)
   - In the ride video creation sheet, subscribers of the existing Ultra tier can
     pick a new "Tactical" style. The server renders the user's OWN recorded route
     as a cinematic "satellite operation" style video (military-HUD look):
     radio-briefing intro, stylized satellite map search, then the user's route
     played back with a tracking marker, and a mission-style outro.
   - All imagery is licensed/free content: Mapbox satellite tiles (our API key),
     Wikimedia Commons photos (CC), Creative Commons music (attribution in-app),
     and synthetic voice lines generated by our own server-side TTS.
   - No third-party people are tracked: the video only visualizes the user's own
     recorded GPS track, same data source as every existing video style.
   - Content is unique per render (randomized cities/codes) for variety; this is
     purely cosmetic randomization of the intro sequence.

DEMO ACCOUNT: same as previous reviews (Review Tester). To try Tactical:
Profile is already Ultra-enabled for the demo account. Record or open a ride ->
"Video" -> style "Tactical" -> Create. Rendering takes ~10-15 minutes; the video
appears in the Videos tab with a push notification when ready.

No changes to data collection, permissions, or purchases in this build
(Tactical is part of the EXISTING Ultra subscription; no new IAP products).
```
